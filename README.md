# Airbnb Data Analysis Using SQL Server

## Project Overview
This project involves analysing Airbnb listing data using Microsoft SQL Server. The practical explores Airbnb listings, pricing and customer reviews to answer different questions and gain insights from the data.

## Dataset
The project consists of three tables:
- Airbnb_Listing
- Airbnb_Pricing
- Reviews

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## SQL Concepts Applied
- SELECT and WHERE statements
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- Aggregate Functions (COUNT, AVG, MIN, MAX)
- GROUP BY and ORDER BY
- Subqueries
- CASE statements
- String Functions (UPPER)
- Date Functions (DATEADD, GETDATE)
- Pattern Matching (LIKE)

## Analysis Questions
- Which room type has the highest number of reviews?
- What is the average price per room type?
- Which listings have no reviews?
- What is the most recent review date for each listing?
- Which listings are priced above the average price?
- Which listings are considered popular based on their number of reviews?
- Which listings are located in neighbourhoods containing the word 'park'?

## Project Objective
The objective of this project is to develop practical SQL skills by querying, joining and analysing Airbnb data to answer questions about listing performance, pricing and customer reviews.

## Key Learning Outcomes
- Understanding how to combine data from multiple tables.
- Applying aggregate functions to summarise data.
- Using subqueries to solve analytical problems.
- Applying conditional and date-based filtering.
- Writing SQL queries to answer practical business questions.
